მიკროფონი არ ირთვება

აპში: iPhone — პარამეტრები → სამი სიმი → მიკროფონი; Android — პარამეტრები → აპები → სამი სიმი → ნებართვები → მიკროფონი. ბრაუზერში: iPhone — მისამართის ზოლში „aA“ → ვებსაიტის პარამეტრები → მიკროფონი; Android/Chrome — ბოქლომის ხატულა → ნებართვები. მიკროფონს მხოლოდ https:// მისამართზე რთავს ბრაუზერი.

რა წყობაზეა აწყობილი?

ტრადიციული ფანდური: სიმი 1 — ლა (A3, 220 ჰც), სიმი 2 — დო♯ (C♯4, 277.18 ჰც), სიმი 3 — მი (E4, 329.63 ჰც). პარამეტრებში შეგიძლია მთელი წყობა ნახევარტონებით გადაწიო, ოქტავა შეცვალო ან A4 კალიბრაცია (430–450 ჰც) დააყენო.

წერს „ოქტავით დაბლა/მაღლა“

სიმი სწორ ნოტზეა, მაგრამ ოქტავით სხვაგან. ჩვეულებრივ ეს ნიშნავს, რომ სიმი ძალიან მოშვებულია (ან ძალიან მოჭერილი). თუ შენი ფანდური განზრახ სხვა ოქტავაშია, შეცვალე „ოქტავა“ პარამეტრებში.

ისარი არ ჩერდება ხმაურიან ოთახში

ჩამოკარი ცოტა ხმამაღლა და ტელეფონი ფანდურთან ახლოს მიიტანე. „ავტომატური მგრძნობელობა“ თავად ზომავს ხმაურს; შეგიძლია გამორთო და მგრძნობელობა ხელით დააყენო.

Support

Frequently asked questions

The microphone won’t turn on

In the app: iPhone — Settings → Sami Simi → Microphone; Android — Settings → Apps → Sami Simi → Permissions → Microphone. In a browser: iPhone — “aA” in the address bar → Website Settings → Microphone; Android/Chrome — lock icon → Permissions. Browsers only allow the microphone on https:// pages.

What tuning does it use?

The traditional panduri: string 1 — A3 (220 Hz), string 2 — C♯4 (277.18 Hz), string 3 — E4 (329.63 Hz). In settings you can transpose the whole tuning by semitones, change the octave or set the A4 calibration (430–450 Hz).

It says “an octave too low / high”

The string is on the right note but in a different octave — usually it is far too slack (or too tight). If your panduri is deliberately in another octave, change “Octave” in settings.

The needle won’t settle in a noisy room

Pluck a little harder and hold the phone close to the panduri. “Automatic sensitivity” measures the room noise for you; you can switch it off and set sensitivity by hand.

Does it work offline?

Yes. The app works fully offline; the browser version does too after the first visit.
