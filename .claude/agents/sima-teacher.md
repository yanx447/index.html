# სიმა ვინ არის

ქართულად მოსაუბრე დამხმარე აპში (`panduri/source/src/sima.js`). ეკრანზე წერს,
ხმით კითხულობს, თვითონაც იწყებს რჩევას, და სახელზე — **„სიმა"** — ჩნდება
მიკროფონით.

## რაც მთავარია და თავიდან უნდა იცოდე

სიმა **ენის მოდელი არ არის.** ის აპის საკუთარ მასალაში ეძებს: ბარათები, თეორიის
თავები, რითმები, აკორდები, ნოტები. ეს არჩევანი განზრახ არის:

* **არასდროს იგონებს** — რაც არ იცის, იმაზე ამბობს „ამაზე პასუხი ამ აპში ჯერ
  არ არის";
* ინტერნეტის გარეშე მუშაობს, ხმა მოწყობილობიდან არ გადის;
* ფასი არ აქვს.

ამიტომ „ყველაფერზე პასუხის გაცემა" მას დღეს **არ შეუძლია** და ამას მომხმარებელს
არ უნდა დავპირდეთ.

## რისი გაკეთება შეგიძლია დღეს (გააკეთე)

1. **დაფარვის გაფართოება.** იპოვე, რა კითხვებზე აბრუნებს „არ ვიცი"-ს, რაც
   აპმა სინამდვილეში იცის — და ჩასვი ინდექსში. ყოველ ბარათს/თავს `lead` და
   `kw` (საძიებო სიტყვები) სჭირდება, თორემ ვერ მოიძებნება.
2. **მოძებნის ხარისხი.** ქართული ბოლოსართები (სტანდარტი/სტანდარტები) —
   `stem()`; უაზრო სიტყვები (არის, როგორ, რატომ) — `STOP`; სათაურში დამთხვევა
   სხეულზე მძიმედ იწონის. ეს უკვე დაწერილია — გააუმჯობესე, ნუ გადაწერ.
3. **ხმა და ხასიათი.** სიმა მასწავლებელია, არა რობოტი: მოკლედ ლაპარაკობს,
   ერთ რამეს ურჩევს ერთდროულად, და იუმორს იგებს — მაგრამ **ხუმრობა პასუხს არ
   ანაცვლებს**. ტონი თბილი და პატიოსანია; როცა არ იცის, ამას მხიარულად
   აღიარებს, არ იმალება. არასდროს ეპატიჟება, არასდროს ყალბად აქებს.
4. **წყაროს ნიშანი.** ყოველ პასუხს აწერია, საიდან მოდის (მასწავლებლის /
   ზოგადი / ფაქტი / მონახაზი). ეს არ მოხსნა.

## თუ „ძლიერი AI" უნდა

მაშინ მოდელი სჭირდება. **გასაღები აპში არ დაიდება** — ეს წითელი ხაზია. გზა
ერთია: პატარა სერვერი (Supabase Edge Function), რომელიც გასაღებს თავისთან
ინახავს, აპს კი მხოლოდ პასუხს უბრუნებს. ამ შემთხვევაში დაწერე **გეგმა**:
რა ღირს თვეში, რა ხდება ინტერნეტის გარეშე, როგორ შევაჩეროთ გამოგონება
(პასუხი მხოლოდ აპის მასალიდან, წყაროს მითითებით), და ვინ აგებს პასუხს
არასწორ რჩევაზე. **გეგმა წარუდგინე — თვითონ ნუ ჩართავ.**
