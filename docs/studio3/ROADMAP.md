## შემდეგი ერთი ეტაპი (რეკომენდაცია)

**Phase 2a — stem-ები, რომლებიც ინახება, და ხილული processing job-ები (მოწყობილობაზე).**

რატომ ეს: ეს დღეს pipeline-ის ყველაზე დიდი ფუნქციური ხარვეზია — გაყოფილი stem-ები სიმღერის
დახურვისას იკარგება და წუთობით გამოთვლა თავიდან ეშვება (AI-STUDIO.md §7 #8). არსებული ძრავებით
(Spleeter / Demucs) დასრულებადია, სერვერს, ახალ მოდელს და კონფიდენციალურობის ახალ გადაწყვეტილებას
არ ითხოვს, და Phase 3-სა (შესწორებადი ანალიზი) და 5-ს (სწავლა stem-ებით) მყარ საფუძველს აძლევს.

რას მოიცავს:
1. გაყოფის შედეგი IndexedDB-ში (Int16 PCM ან Opus), მოდელის/ძრავის/ვერსიის და მონაკვეთის
   (`from`/`len`) ჩანაწერით; schema 3-ში `stems[].assetId`, `kept: 'device'`; სიმღერასთან ერთად
   იხსნება; ზომის შეფასება (`navigator.storage.estimate()`) და წაშლა.
2. `ProcessingJob` Studio-ში: queued · decoding · separating · complete · partial · error ·
   cancelled — პროგრესი, გაუქმება, ხელახლა ცდა; არსებული worker-ის შეტყობინებებზე აგებული;
   job-ების სია გვერდით პანელში.
3. თითო stem-ის WAV export და Solo/Mute/Gain პანელიდან (ფუნქციები უკვე არსებობს).
4. ტესტები: შენახული stem-ის ხელახლა გახსნა (Int16-ის ცდომილების ფარგლებში იგივე), გაუქმება/ხელახლა
   ცდა, მეხსიერება ტელეფონზე, ზომის ლიმიტი.

არ მოიცავს: სერვერის GPU-ს, ქართული საკრავების გაყოფას, ახალ მოდელებს.

## შემდეგ

* **2b** — მთელი სიმღერის 4-stem გაყოფა ტელეფონზე (სეგმენტებად, შედეგი პირდაპირ Int16-ში/IndexedDB-ში);
  analysis worker-ში (main thread-ის გათავისუფლება).
* **3** — ერთიანი მოვლენების მოდელი (წამი ↔ tick, ცვლადი ტემპი), ერთი piano roll ორივე ტიპზე,
  AI-ის ნედლი შედეგი + შესწორება + provenance ცალ-ცალკე; ორი `AudioContext` → ერთი; მასწავლებლის review.
* **4** — სიმღერის ტრანსკრიფციიდან არანჟირება (Original / Simplified), წყობის profile-ები
  (ზედმეტ დაჭიმვაზე გაფრთხილებით).
* **5** — falling TAB მუსიკალურ დროში, არანჟირების Learn რეჟიმი, მიკროფონით შეფასება latency-ის
  კალიბრაციით და confidence-ით.
* **6–8** — როგორც სპეციფიკაციაშია; თითო ეტაპი დამოუკიდებელი benchmark-ით.

## გადაწყვეტილებები, რომლებიც მფლობელს ან მასწავლებელს ეკუთვნის

* მასწავლებლის 4 რითმის დარტყმების ხანგრძლივობა (დღეს თანაბარია და ასეც წერია).
* Studio-ს 133 ახალი სტრიქონის თარგმნა 14 ენაზე (დღეს ინგლისურად ჩანს).
* Panduri Studio-ს ძველი standalone განლაგების წაშლა (Phase 3-ის შემდეგ).
