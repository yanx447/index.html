**არ იყოფა**, და UI ამას პირდაპირ წერს (`s3s.geo`, Stems view). ამ დოკუმენტში: რა გაიზომა დღეს ნამდვილ
ჩანაწერებზე, რა არ არის ცნობილი, რა გზები არსებობს და როგორ შემოწმდება, სანამ რომელიმე მათგანი

## 2. ბაზისური ხარისხი ქართულ სიმღერაზე (fact, გაზომილი)

`node qa/sep-bench.cjs 40 d4,d4o50,d4s2,d6,spl docs/studio3/data/sep-bench-<from>.json <from>` (შედეგები
`docs/studio3/data/`-შია) — ბანის „აჭარული", რომელიც ორ ცალკე
ჩანაწერად არსებობს: ხმა (`VOCAL.mp3`) და მუსიკა (`MUSIC.mp3`). მიქსი = მათი ჯამი, ასე რომ სწორი
პასუხი ზუსტად ცნობილია. SDR = 10·log₁₀(Σs² / Σ(s−ŝ)²), ორივე არხზე; „მუსიკა" = ყველა არა-ვოკალური
stem-ის ჯამი. 40 წამიანი სამი მონაკვეთი, WebGPU, Apple Silicon. SDR დეტერმინისტულია: ორჯერ გაშვებულზე
ციფრი-ციფრამდე იგივე გამოვიდა. დრო ცვალებადია (მანქანის დატვირთვა; პირველ ვარიანტში მოდელის ჩატვირთვაც
შედის) — ცხრილში ორი გაშვების დიაპაზონია.

გადაწყვეტილებები ამ გაზომვიდან:
* **50 % overlap არ ჩაირთო**: ერთ მონაკვეთზე +0.43 dB, მეორეზე −0.34 — სტაბილური გაუმჯობესება არ არის.
* **2 გავლა ჩაირთო როგორც არჩევანი („მაღალი · 2 გავლა")**: სამივე მონაკვეთზე ან უკეთესია (+0.03…+0.42
  dB ვოკალზე), ან იგივე; არცერთზე უარესი. ~1.8× ნელია, ამიტომ ნაგულისხმევი არ არის.
* **6 stem ვოკალზე სამივე მონაკვეთზე უკეთესია** (+0.29…+2.25 dB), მუსიკაზე — არაერთგვაროვნად. ეს
  შეტყობინებად წერია Stems view-ში; ავტომატურად არ ირჩევა.
* **Spleeter (მსუბუქი ძრავა) ამ მასალაზე თითქმის არ ყოფს** (ვოკალი 0.0–0.7 dB). მხოლოდ-ხმის ჩანაწერს
  76 %-ით „other"-ში სვამს, მხოლოდ-მუსიკისას 88 %-ით „drums"-ში; Demucs-ის PyTorch საცნობაროსთან
  (`ai-build/test.wav`) არცერთი stem არ ემთხვევა (SDR −11 … +1 dB, bass თითქმის ცარიელია). ონლაინ
  კონვერტაციაში (2026-10-28, TensorFlow-ის გარეშე დაწერილი reader-ით) **ყველა BatchNorm-ის moving
  mean = 0, variance = 1** — ინიციალიზაციის მნიშვნელობები. BatchNorm-ის InstanceNorm-ით შეცვლამ
  ვერ გამოასწორა (ყველა stem თანაბარი გახდა). **მიზეზი დადასტურებული არ არის**; გამოსწორებას
  სჭირდება TensorFlow + ორიგინალი checkpoint, ან უკვე გადამოწმებული ONNX export. მანამდე UI წერს
  გაზომილ რიცხვებს და ურჩევს ზუსტ ძრავას (`s3s.engD`).

  drums · bass · other (+ guitar · piano). მოდელი ყოფს მხოლოდ იმ კლასებად, რაზეც ისწავლა.
* ცალკე კლასის სასწავლად საჭიროა **მრავალტრეკიანი ჩანაწერი**: თითო საკრავი ცალკე ტრეკზე, ერთ
  სიმღერაში. ქართული ანსამბლის ასეთი ღია მონაცემთა ბაზა ჩვენთვის ცნობილი არ არის.
* ახლო ტემბრის საკრავები (ფანდური/ჩონგური — ორივე ჩამოკრული სიმებიანი; გარმონი/სალამური — ორივე
  მდგრადი ბგერა) ერთმანეთისგან ყველაზე რთულად იყოფა — hypothesis, ჯერ შეუმოწმებელი ქართულ მასალაზე.

## 5. ტესტირების გეგმა

### მონაცემი
1. **ახლავე ხელმისაწვდომი** — ხელოვნური მიქსები ცალკე ნამდვილი ჩანაწერებიდან: მასწავლებლის ფანდური
   (`რითმები/*.wav`, `ფანდურის თითოელი სიმი/*.wav`) + ბანის ხმები (`VOCAL.mp3`) + ბანის მუსიკა
   (`MUSIC.mp3`); სწორი პასუხი ზუსტად ცნობილია. სატესტო და ლექსიკონის ჩანაწერები არ ერევა.
2. **ჩასაწერი** — თითო საკრავი ცალკე, ახლო მიკროფონით, ერთ სიმღერაში (მრავალტრეკიანი სესია):
   ფანდური, დოლი, გარმონი, ჩონგური, სალამური, ხმები ცალ-ცალკე. სულ მცირე 3 დამკვრელი თითო საკრავზე,
   2 ოთახი. მონაწილეების წერილობითი თანხმობა ჩანაწერის კვლევაში გამოყენებაზე; ლიცენზია განსაზღვრული.
3. **დახურული სატესტო ნაკრები** — ჩანაწერები, რომლებიც არც ლექსიკონში და არც ტრენინგში არ მოხვდა
   (სხვა დამკვრელი/ანსამბლი).

### მეტრიკები
* SDR და SI-SDR თითო საკრავზე (იგივე ფორმულა, რაც `qa/sep-bench.cjs`-ში; შედეგები JSON-ში, ვერსიით).
* „გაჟონვა": სხვა საკრავის ენერგიის წილი ამ საკრავის stem-ში (`qa/geo-routing.cjs`-ის მეთოდით).
* მოსმენის ტესტი მასწავლებელთან: „ეს მხოლოდ ფანდურია?" — 5 ქულიანი სკალა, ბრმად, 10+ მონაკვეთი.
* დრო და მეხსიერება ტელეფონზე (iPhone/Android, რეალური მოწყობილობა).

### როდის შეიძლება ეწეროს „მხარდაჭერილია"
* მედიანური SDR ≥ 6 dB დახურულ ნაკრებზე **და** მასწავლებლის მოსმენის საშუალო ≥ 4/5, თითო საკრავზე ცალკე;
* შედეგი სულ მცირე 3 სხვადასხვა დამკვრელზე;
* ტელეფონზე 30 წამი ≤ 2 წუთში, მეხსიერების შეცდომის გარეშე.
მანამდე UI ამბობს: „კვლევა, არა ფუნქცია" და აჩვენებს მხოლოდ §1-ის გაზომილ რიცხვებს.

### საფეხურები
1. A-ს პროტოტიპი `qa/`-ში (UI-ს გარეშე): ფანდურის ლექსიკონი `media/strings`-იდან → NMF → SDR ნაკრებ 1-ზე.
2. თუ ფანდურზე SDR ≥ 4 dB — D (Demucs-ის other/guitar → A) და მოსმენა მასწავლებელთან.
3. ჩაწერის სესია (ნაკრები 2) — მფლობელის გადაწყვეტილება და ბიუჯეტი.
4. B ან C — მხოლოდ ნაკრები 2-ის შემდეგ.
