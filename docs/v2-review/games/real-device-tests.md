# თამაშები — შემოწმება ნამდვილი ფანდურით

ავტომატური ტესტები (`qa/games-*.cjs`) მიკროფონის ნაცვლად **ვირტუალურ ფანდურს** იყენებს. აპის დეტექტორს
მასწავლებლის ჩაწერილი ნოტები და აკორდები მიეწოდება. ეს ტესტები აჩვენებს, რომ ჯაჭვი მუშაობს: ხმა → დეტექტორი →
თამაშის წესები. ის არ აჩვენებს, როგორ ესმის ტელეფონს ოთახში. ქვემოთ მოცემული 12 სცენარი ამ ხარვეზის შესავსებადაა:
თითოეული ერთხელ ნამდვილ ფანდურზე უნდა დაიკრას.

სვეტი „ვირტუალური შედეგი“ იმას აჩვენებს, რა მივიღეთ იგივე ტესტში სიმულირებული მიკროფონით. ნამდვილი
მოწყობილობის შედეგი ცოტა სხვა იქნება — მთავარია, „ჩავარდნის ნიშანი“ არ გამოჩნდეს.

## მომზადება (ერთხელ თითო მოწყობილობაზე)

1. **თამაშები → ⚙ → მიკროფონი და დრო → კალიბრაცია.** ოთახის ხმაური, მგრძნობელობა, ღია სიმები, დაყოვნება.
2. **დაკვრის დროის გასწორება.** 4 ათვლის შემდეგ ყოველ დაწკაპუნებაზე ღია სიმი დაუკარი. შედეგს ჩაიწერე (ms, „გაბნევა ±“).
3. **აწყობის შემოწმება.** სამივე სიმი ±15¢-ში უნდა იყოს. თუ არა — ტიუნერი.
4. თამაშის საწყის გვერდზე ჩართე მიკროფონი და დაუკარი სიმი. „მიკროფონის შემოწმებაში“ ხუთივე ხაზი უნდა გამწვანდეს:
   მიკროფონი, სიგნალი, ბოლო ნოტი, კალიბრაცია, აწყობა.

ტელეფონი ფანდურიდან 30–60 სმ-ზე დადე. ტესტი სჯობს ჯერ ყურსასმენის გარეშე გაიარო, შემდეგ — Bluetooth-ით, თუ იყენებ.

## შედეგის ჩაწერა

თითო სცენარზე ჩაიწერე: მოწყობილობა (ტელეფონი/ბრაუზერი), მიკროფონი (ჩაშენებული/ყურსასმენი), ოთახი,
რა ნახე ეკრანზე, ✓ ან ✗. ✗-ის შემთხვევაში ⚙ → დეველოპერი → „დიაგნოსტიკის პანელი“ ჩართე (ჩანს მხოლოდ შეხების ტესტის ან
მფლობელის რეჟიმში). ის აჩვენებს ამოცნობილ ბგერას, სანდოობას, დროის აცდენასა და დონეს. ეს მონაცემები გამოგვიგზავნე.

## რა არ შემოწმდა ავტომატურად

* ჩუმი აკორდის ცვლილება ძლიერის შემდეგ (C → Dm, აჭარულის ↓ ↑>-ის შემდეგ): სინთეზურ აკორდებზე დეტექტორი ზოგჯერ ვერ
  იგებს, მასწავლებლის ჩაწერილ აკორდებზე — იგებს. სცენარი 10 და „ბენდთან ერთად“ ამას ნამდვილ ფანდურზე აჩვენებს.
* ექოს შემოწმება („ბენდთან ერთად“): ვირტუალური „დინამიკით“ შემოწმდა. ნამდვილ ტელეფონზე echo cancellation მოქმედებს,
  ამიტომ რიცხვები განსხვავდება.
* ოქტავის წესი თამაშებში ერთი ოქტავის სიზუსტეს ითხოვს (ლადების მონადირე). ფანდურის ფიზიკური ჟღერადობა ზოგ ლადზე
  (A სიმი, მაღალი ლადები +23…+58¢) ამ ფარგლებში თავსდება, მაგრამ ინსტრუმენტის ინტონაცია მოწყობილობაზე უნდა გადამოწმდეს.
