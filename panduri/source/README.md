# ფანდური — წყარო / source

ეს არის აპის **ხელით დაწერილი წყარო**. `../app/` მისი აწყობილი შედეგია და
ხელით არ იცვლება — ყოველი აწყობა მას თავიდან წერს.

## აწყობა

```bash
cd panduri/source
python3 build.py
```

შედეგი:

| ფაილი | რა არის |
|---|---|
| `dist/app/` | PWA — ის, რაც `../app/`-ში იდება |
| `dist/artifact.html` | მთელი აპი ერთ ფაილად (ლიმიტი **16 MiB**) |
| `dist/panduri-pwa.zip` | იგივე PWA არქივად |

აწყობა დეტერმინისტულია: ერთი და იგივე წყარო ერთსა და იმავე ვერსიის hash-ს
იძლევა (ბოლო ხაზში იბეჭდება). გამოსავალში უნდა ეწეროს **`819 poses`** — თუ
ნაკლებია, 3D ხელის მონაცემი აკლია.

სჭირდება: `python3` (Pillow-ით), `node` (3D-ის გადასაწყობად).
**დამატებითი დაყენება არ არის საჭირო** — აწყობა მხოლოდ ამ საქაღალდის ფაილებს
კითხულობს, პლუს ჩანაწერებს `../app/media/`-დან.

## რა სად არის

| საქაღალდე | რა |
|---|---|
| `src/*.js` | ყველა მოდული. ჩვეულებრივი JS, ფრეიმვორკის გარეშე, ერთი სივრცე `PD`. რიგი `build.py`-ს `ORDER`-შია. |
| `src/app.css` | მთელი აპის CSS, ერთ ფაილად. |
| `src3d/` | 3D მარცხენა ხელი: `hand3d.src.js` (გამომსახველი), `build_hand3d.py` (პოზებს კოდში ჩააშენებს). |
| `render/` | პოზების ამომხსნელი. `out/poses_final.json` — **819 ამოხსნილი პოზა, ძვირად მიღებული; ნუ წაშლი.** |
| `pwa/` | manifest, service worker, ხატულები, მაღაზიის სურათები. |
| `media_inline/` | ჩანაწერების მსუბუქი ასლები ერთფაილიანი აწყობისთვის. |
| `assets/`, `ext/` | სურათები; ჩაშენებული ტიუნერი („სამი სიმი"). |
| `qa/` | შემოწმების სკრიპტები. |
| `supabase/` | სერვერის SQL. |

## რა არ დევს აქ და რატომ

* **`dist/`** — აწყობის შედეგი. `python3 build.py` მას თავიდან ქმნის.
* **`../app/media/`** — მასწავლებლის ჩანაწერები (32 MB). რეპოზიტორიაში ერთხელ
  ინახება, აწყობილ აპთან ერთად; `build.py` იქიდან კითხულობს. მეორე ასლი
  საჭირო არ არის.
* **`render/out/p_*`** — შუალედური რენდერები (219 MB). ამოხსნის პროცესის
  ნარჩენია, შედეგი `poses_final.json`-შია.
* **QA-ს ჩანაწერები და ეკრანის სურათები** (157 MB) — ხელახლა გადაიღება.
